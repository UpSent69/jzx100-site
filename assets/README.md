# Материалы

`/assets` — оригиналы, их не меняют. `/assets/web` — всё, что реально отдаётся
браузеру. Пересобирается скриптами из `/tools`, руками там ничего не правится.

## Первый экран, слои

Кадр разобран так, что `hero-plate` + `hero-letters` + `hero-car`, положенные
друг на друга при непрозрачности 1, дают исходную композицию.

| Файл | Что это |
|---|---|
| `hero-plate.*` | фон без надписи |
| `hero-letters.*` | вся надпись одним слоем — для мобильных, где буквы гаснут разом |
| `hero-letter-{m,a,r,k,i1,i2}.png` | отдельные знаки для поочерёдного ухода |
| `hero-letters.json` | положение каждого знака в долях кадра |
| `hero-car.*` | силуэт машины, верхний слой |

Три вещи, которые видно не сразу и на которые легко наступить:

1. **`hero-composed` отгрейжен, `hero-clean` — нет.** Композиция темнее, глуше
   и с виньеткой. Поэтому фон собран не вклейкой чистого кадра в композицию —
   такая вклейка читалась бы силуэтом букв, — а приведением чистого кадра к
   грейду композиции целиком. Приведение локальное, по среднему и разбросу
   в широком окне.
2. **Белая точка в композиции опущена до 226.** Надпись непрозрачная, но по
   разнице с чистым кадром выглядит полупрозрачной. Маска считается
   относительно реального цвета краски (226, 226, 228), иначе на светлом
   отбойнике сквозь буквы проступает стена.
3. **Машина закрывает середину слова.** A, R и K видны фрагментами, K вообще
   разорвана надвое. Знаки нарезаны не по связным областям, а вертикальными
   линиями по пустым столбцам между ними.

Катакана и подпись `TOYOTA MARK II JZX100 1996 — 2002` в фон не перенесены:
на сайте они набираются текстом.

## Видео

Фоновые (`hero-bg`, `motion-bg`) — без звука, в mp4 и webm. Карточные
(`card-1`, `card-2`) — со звуком, mp4. Постеры карточек — первый кадр ролика.

`hero-bg` и `motion-bg` не проигрываются сами — их перематывает прокрутка.
Поэтому у них ключевым сделан каждый кадр: перемотка попадает на ближайший
ключевой, и при обычном интервале картинка менялась бы рывками через раз.
Ход вперёд-назад им не нужен — назад отматывает сам скролл.

## Как заменить ролик третьего экрана

1. положить его в `assets/motion-run.mp4`, заменив старый;
2. `bash tools/encode_video.sh` — он достроит ролик до 60 кадров, пережмёт
   под перемотку прокруткой и заново вырежет из **пережатой** копии
   `motion-open`, статичный кадр, с которого сцена открывается. Вырезать его
   из оригинала нельзя: цвет после кодека чуть другой, и подмена станет видна;
3. проверить `motion-open` глазом — это то, что видно до подмены;
4. если у нового ролика другое соотношение сторон, поправить `--motion-crop`
   у `.motion` в `src/styles/screens.css` и ширину в `srcset` в `index.html`.

## Пересборка

```
python tools/hero_layers.py     # фон и слои надписи
python tools/hero_car.py        # силуэт машины (rembg, isnet-general-use)
python tools/web_images.py      # облегчённые кадры
bash   tools/encode_video.sh    # пережатие роликов (нужен ffmpeg)
python tools/web_cleanup.py     # варианты слоёв с прозрачностью, сводка по весу
```

Порядок важен: `hero_car.py` режет силуэт из `hero-plate`, который делает
`hero_layers.py`.
